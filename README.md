# For Sakshi ♡ — Unlocked Preview Version

An interactive birthday website for Sakshi, made with love.

**This is the UNLOCKED PREVIEW version.** There is no lock screen at all —
the site opens straight to the intro ("Open your surprise ♡") and the full
site works immediately, any time. Use it to preview and test everything on
phone, tablet and desktop.

⚠️ Do NOT share this version's link with Sakshi or anyone you don't want
seeing the surprise early — it opens for anyone, anytime.

## Contents

- `index.html` — the whole site (plain HTML, CSS and JavaScript, no build step)
- `assets/` — all photos and the birthday song as separate files
  (`moment-01.jpg` … `moment-21.jpg`, `wish-01.jpg` … `wish-08.jpg`,
  `memory-1.jpg` … `memory-3.jpg`, `hero-bg.webp`, `hero-bg-800.webp`,
  `birthday-song.mp3`)

## How to run locally

Open `index.html` in any browser, or serve the folder with any static
server, e.g.:

```
npx serve .
```

## How to host

Upload this folder (or this ZIP) to any static host — Netlify, Vercel,
Cloudflare Pages or GitHub Pages. On Netlify, just drag the folder or ZIP
onto [Netlify Drop](https://app.netlify.com/drop). No build settings are
needed; `index.html` is the entry point.
